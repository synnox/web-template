Firmware walkthroughs

BIOS Update Guide by Motherboard Vendor

Start with your exact motherboard or laptop model, download firmware only from its manufacturer support page, and then use the matching walkthrough below to understand the update tool.

Before you begin: confirm the model and revision, keep the system on stable power, and never interrupt an update in progress. A BIOS file for a different model can leave the machine unable to boot.

Why update BIOS before HWID ban recovery?

A BIOS update matters before HWID ban recovery when a game requires a newer security baseline or the workflow depends on current motherboard firmware. Some games refuse to launch until TPM 2.0 and Secure Boot are switched on — the requirement documented on the Riot Vanguard hub and the EA AntiCheat hub — or a hardware ban has sent them looking for what the motherboard actually exposes to anti-cheat software in the first place. TPM 2.0 and Secure Boot Anti-Cheat (2026) covers which firmware settings those checks read, and why an out-of-date BIOS can hide the options entirely.

A firmware update on its own is not a ban fix. It refreshes the code your board runs; it does not change the identifiers an anti-cheat already recorded. What should you do after a BIOS update?

A firmware update normally drops every setting back to its default, so re-enable TPM, Secure Boot, and your memory profile before you test a game again. Plenty of launch failures reported straight after a flash are really a reset firmware option rather than an active ban, and HWID Spoofer Not Working? 2026 Fix Guide works through those cases in the order they are worth checking.
