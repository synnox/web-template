What is Phanuel?

Phanuel is the anti-cheat name shown by the FragPunk PC launcher. The installed stack is also associated with NEAC naming, but public FragPunk material gives players the Phanuel label and does not publish a full component map. This hub is therefore specific to FragPunk.

FragPunk support documentation confirms that Phanuel can block launch and that Secure Boot is part of the platform checks on affected configurations. Bad Guitar Studio also combines automated monitoring with manual review for enforcement. Those facts are stronger than guessing at a private telemetry packet.

TraceX Spoofer rewrites its supported Windows identifiers once and can then be deleted. TraceX does not modify Phanuel, NEAC, Secure Boot, or the FragPunk client.

How does Phanuel track hardware?

Phanuel's public documentation does not enumerate HWID fields. The concrete Windows surfaces available to a PC anti-cheat are `Win32_BaseBoard`, `Win32_DiskDrive`, and `Win32_PhysicalMemory`, with the SMBIOS Type 2 baseboard serial supplying board data and `IOCTL_STORAGE_QUERY_PROPERTY` exposing lower-level physical-disk descriptors.

Software and network identity can include `MachineGuid` at `HKLM\SOFTWARE\Microsoft\Cryptography`, volume and Windows installation values, and MAC enumeration. A new FragPunk account or client reinstall leaves those machine inputs intact, which is why account identity and device identity must be discussed separately.

FragPunk documents Secure Boot troubleshooting. Windows exposes the TPM 2.0 endorsement key through TBS, but neither Bad Guitar Studio nor the public launcher FAQ confirms that Phanuel stores that key as an identifier. Secure Boot state is confirmed; the private TPM field list is not.

A composite or fuzzy model can combine board, disk, OS, network, and boot-state signals. Because Phanuel is FragPunk-specific, the exposure concerns a returning FragPunk machine under another account. It is not evidence that one Phanuel action bans games outside Bad Guitar Studio's service.
