How should you read HWID spoofer detection results?

“Undetected” means an authorised operator published an undetected result for the displayed product version and anti-cheat. The timestamp shows when that point-in-time result was recorded; it is not a guarantee about future game or anti-cheat updates.

“Investigating” means the available signal is not conclusive. “Working” is shown only when no published result is available; it is not a point-in-time undetected claim or a promise about future anti-cheat updates.

Each engine on this list reads a different mix of firmware, storage, network, and platform signals, which is why one label never generalises across the set. How anti-cheat reads your hardware breaks down what each category of value actually is, and an honest look at the risks involved covers what a compatibility label does and does not promise.

What happens when detection status changes?

Each anti-cheat is tracked independently. A detected or investigating result remains visible until a newer audited check is published; refreshing one target never makes every other target appear current.

If a newer build is required, download it from the authenticated dashboard only after the affected system returns to a fresh published state. License holders may also receive an operational email when a material compatibility update is available.

Enforcement is administered per publisher, so a change against one engine does not automatically move every title that uses it. To see which engine guards a specific game, open the full list of supported games.
