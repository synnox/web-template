How does Ironshield track hardware?

IRONMACE confirms hardware and process monitoring but does not enumerate each field. On Windows, board and memory data can be exposed through `Win32_BaseBoard`, `Win32_PhysicalMemory`, and the SMBIOS Type 2 baseboard serial. Physical-disk descriptors are available through `Win32_DiskDrive` and `IOCTL_STORAGE_QUERY_PROPERTY`.

The OS layer includes `MachineGuid` at `HKLM\SOFTWARE\Microsoft\Cryptography`, volume and installation identifiers, and MAC enumeration. Those values help distinguish a changed account from a changed machine. A Dark and Darker reinstall does not normally alter any of them.

The TPM 2.0 endorsement key and Secure Boot are security-state surfaces, with TPM operations available through TBS and HVCI describing virtualization-based code-integrity protection. Ironshield's public policy does not state that it stores the key, so the careful claim is that boot and TPM state can complement the hardware profile.

Composite or fuzzy matching can join board, disk, Windows, network, and security-state inputs while tolerating a normal component replacement. Because Ironshield is tied to Dark and Darker, the exposure is repeat accounts or sessions on the same device, not a claim of automatic cross-game propagation.
