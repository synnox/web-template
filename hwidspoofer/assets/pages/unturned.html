FAQ

What should Unturned players know about HWID bans?

Unturned HWID ban FAQs explain BattlEye enforcement and the supported TraceX workflow.

What message proves I have an Unturned game ban?

SDG's help center identifies `You are banned from playing multiplayer.` as the BattlEye game-ban message. `You are banned from this server [...]` points to a community-host ban, while `You are banned from playing on VAC secure servers.` is a separate VAC action. Steam also displays a notification and a profile label for game or VAC bans. If neither appears, a timeout, module kick, or BattlEye service error is not proof of a ban.

Does Unturned use BattlEye, VAC, or both?

Both. SDG says BattlEye detections apply Steam game bans, while VAC is Valve's separate anti-cheat path and was used more heavily before BattlEye arrived. Community-server bans form a third category controlled by the host. Do not treat a Steam game-ban label as a VAC label: the in-game message distinguishes them. BattlEye protection is also configurable per server, so a kick from one server does not by itself describe every Unturned session.

Does Unturned really issue HWID bans?

Yes, but the scope matters. SDG's June 3, 2022 update notes say Unturned's vanilla ban command also bans the player HWID, and its May 31, 2025 community blog describes built-in detection of attempts to bypass server HWID bans. BattlEye separately confirms that it may process hardware-device identifiers such as serial numbers. Those sources establish real hardware enforcement; they do not say every BattlEye Steam game ban uses one fixed HWID recipe.

Why did a new Steam account get blocked on the same Unturned PC?

A new Steam account changes the account identifier, not the machine. BattlEye's privacy policy says it may process both game identifiers and hardware-device information, and Unturned's vanilla server ban can include the player's HWID. If the original action is tied only to one account, new credentials are a separate case; if a server or anti-cheat record recognizes the same machine profile, unchanged board, disk, Windows, and network values can expose that relationship again.

Will reinstalling Unturned or formatting Windows clear the ban?

Reinstalling Unturned can repair game or BattlEye files, but it cannot remove a server-side game, VAC, or host ban. A clean Windows install may regenerate `MachineGuid` and filesystem volume metadata. It normally does not replace the SMBIOS Type 2 board serial, motherboard UUID, controller-reported disk serials, physical NIC identity, or TPM-rooted material. Formatting is therefore neither a complete hardware-identity reset nor proof that enforcement is gone.

Which hardware identifiers can BattlEye read for Unturned?

BattlEye publicly confirms the broad category of hardware-device information and identifiers such as serial numbers, but it does not publish Unturned's exact field list. Relevant Windows surfaces include the SMBIOS Type 2 board serial, motherboard UUID, disk firmware and volume serials, physical NIC MAC addresses, and `MachineGuid` under `HKLM\SOFTWARE\Microsoft\Cryptography`. TPM 2.0 endorsement-key material and Secure Boot state are separate platform signals; neither is confirmed as an Unturned ban key.

What does "Hardware ID (HWID) spoofer detected" mean in Unturned?

The "Hardware ID (HWID) spoofer detected" kick appears in player reports, but SDG's official ban article does not list it as the message for a BattlEye game ban. A confirmed game ban shows `You are banned from playing multiplayer.` and produces a Steam notification or profile label. If those signals are absent, diagnose the line as a compatibility or kick first. It does not by itself prove that your Steam account has a global BattlEye ban.

How do I appeal an Unturned BattlEye or server ban?

For the `You are banned from playing multiplayer.` game-ban message, SDG directs you to BattlEye's ban-appeal contact form. Include the exact global ban ID if one appears; BattlEye says to provide the game account identifier, such as your SteamID, when no ID is shown. A `You are banned from this server [...]` action belongs to that community host, not SDG. Confirmed BattlEye global bans are permanent, but the appeal route exists for a mistaken detection.

Does an Unturned ban affect DayZ, Arma 3, PUBG, or Siege?

Not automatically. BattlEye can process the same hardware-information category when any integrated title runs, so an unchanged board, disk, Windows, and network profile creates cross-game recognition exposure. Publishers and individual game integrations still control enforcement scope. An Unturned ban alone is not proof that DayZ, Arma 3, PUBG, or Siege has banned the account; use the literal notice in each title instead of assuming a roster-wide carryover.
