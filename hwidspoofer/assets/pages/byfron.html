What is Byfron?

Byfron developed Hyperion, the anti-tamper technology now deployed by Roblox on Windows. Unlike EAC or BattlEye, this hub is Roblox-only: Hyperion protects the Roblox client and experiences on one platform rather than serving a roster of unrelated PC publishers.

Roblox can connect enforcement across accounts, client integrity, abnormal behavior, and a recurring device profile. That creates account-cascade risk on the same PC, but it is not cross-game propagation in the EAC sense. The relevant boundary is Roblox's own platform and account graph.

How does Byfron track hardware?

Roblox publicly describes Hyperion as Windows anti-tamper technology, not a published field-by-field HWID collector. A user-mode client can still query concrete Windows surfaces: `Win32_BaseBoard`, `Win32_DiskDrive`, and `Win32_PhysicalMemory`, with the SMBIOS Type 2 baseboard serial backing the board view and `IOCTL_STORAGE_QUERY_PROPERTY` exposing lower storage descriptors.

Roblox can supplement hardware context with `MachineGuid` at `HKLM\SOFTWARE\Microsoft\Cryptography`, volume and installation data, and MAC enumeration. These values can remain identical across many Roblox accounts on the same Windows installation, which is why replacing an account does not necessarily replace the device relationship.

The TPM 2.0 endorsement key is reachable through TBS, and Secure Boot state is available to Windows software, but Roblox does not publicly confirm that Hyperion stores that key as part of every device profile. Those are possible inputs, not facts that should be invented to make Hyperion sound like a boot-time kernel driver.

A platform-level composite can use fuzzy matching across board, disk, OS, and network inputs while Roblox adds account and behavior signals. There is no separate cross-publisher roster: the exposure is multiple Roblox accounts and experiences resolving to the same device, not one Roblox action banning an unrelated game.
