FAQ

What should Rust players know about HWID bans?

Rust HWID ban FAQs explain EasyAntiCheat enforcement and the supported TraceX workflow.

Are Rust EAC bans permanent, or do they expire?

Yes. Facepunch's EAC Banned article, updated July 3, 2026, says all EAC bans are permanent and that incorrect rounds are reversed automatically by its servers. The banned Steam account cannot return to EAC-secured Rust servers; it may still access single-player, LAN, or insecure community servers where available. A hardware ban is also permanent and, under Facepunch's separate Second Chances policy, is excluded from the return program.

How do I know whether Rust account-banned me or HWID-banned my PC?

Start with the message and scope. "EAC: Banned" plus a Steam Game Ban confirms an EAC account sanction, not by itself an HWID ban. Facepunch says hardware bans are reserved for repeat offenders. A new account being sanctioned after the same PC returns is consistent with hardware matching or ban-evasion enforcement, but there is no public Rust tool that reveals which serial matched. Do not treat a generic authentication timeout or client-integrity error as proof of an HWID ban.

Will making a new Steam account let me play Rust again on the same PC?

Facepunch's Ban Second Chances article says a one-time offender may buy Rust on a new account only after more than eight months, provided they have not reoffended. Returning sooner is likely to trigger another ban. Repeat cheaters and hardware-banned players are explicitly ineligible, so a new Steam account is not an official workaround for a Rust HWID ban and cannot recover the banned account's items or Game Ban status.

Will reinstalling Windows or formatting my drive clear a Rust HWID ban?

No. A clean install can regenerate MachineGuid under HKLM\SOFTWARE\Microsoft\Cryptography, and a format can change a filesystem volume serial, but neither action rewrites the SMBIOS Type 2 baseboard serial, motherboard UUID, physical disk firmware serials, physical NIC MAC addresses, or TPM 2.0 endorsement key. Wipe-only advice changes part of the profile and leaves the firmware and controller anchors intact.

Which hardware identifiers can EAC compare for a Rust hardware ban?

Relevant collection surfaces are the SMBIOS Type 2 baseboard serial, motherboard or system UUID, physical disk serials queried through storage IOCTLs such as IOCTL_STORAGE_QUERY_PROPERTY, filesystem volume serials, MAC addresses, and Windows MachineGuid. Rust's 2026 secure-server rollout also checks TPM and Secure Boot readiness. EAC does not publish a per-title weighting formula, so anyone claiming one serial is always the decisive Rust value is guessing.

Does Rust require TPM 2.0 and Secure Boot in 2026?

As of Facepunch's March 6, 2026 support update, TPM and Secure Boot are required on selected Rust servers carrying a "secure" tag; Facepunch says a later phase will make the requirement global. Secure Boot reports whether the UEFI chain is trusted, while TPM 2.0 provides hardware-rooted key material such as an endorsement key. This is a platform trust check, not proof that every ordinary server join currently produces an HWID ban.

Why does Steam show "Game Ban" instead of "VAC Ban" for Rust?

Rust uses Easy Anti-Cheat, not Valve Anti-Cheat. Facepunch says an EAC ban on a Steam game adds a "Game Ban" status to the Steam profile and has the same profile-level impact as a VAC status, but EAC and Facepunch made the enforcement decision. The distinction matters for appeals and scope: Valve does not lift a Rust EAC ban, and moving the game to another Steam account is not supported.

Can a Rust EAC ban automatically ban me from Fortnite or Apex Legends?

No automatic roster-wide ban follows from the shared EAC logo. Publishers administer sanctions for their own games, so a Rust ban does not itself ban Fortnite, Apex Legends, or every other EAC title. The exposure is technical: those games can collect the same classes of motherboard, storage, network, Windows, and platform-trust signals. Reusing an already flagged machine profile can therefore create cross-title re-identification risk without making the ban lists identical.

Can I appeal a false Rust EAC ban and recover my Steam account?

Use EAC's decision-appeal form only if you believe the detection was wrong, and keep the reference ID from the ban notice. Facepunch says support tickets or appeals do not remove a confirmed EAC ban; if a round was issued incorrectly, reversals happen automatically server-side. Do not pay anyone promising to clear the Game Ban badge or restore the banned Steam account. TraceX changes supported identifiers; it cannot reverse a publisher sanction.

How does a persistent Rust rewrite differ from session masking?

A temporary session spoofer changes or intercepts values only while it is active, so the old profile can return after reboot and the tool must be present again. TraceX uses a one-time permanent rewrite of its supported identifier set. Run it once, confirm the rewritten values, then delete the tool; no daemon or per-boot session remains. Neither approach restores the banned Steam account, and a rewrite is not permission to ignore Facepunch's rules.
