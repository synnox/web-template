FAQ

What should New World players know about HWID bans?

New World HWID ban FAQs explain EasyAntiCheat enforcement and the supported TraceX workflow.

How do I tell a New World HWID ban from an ordinary EAC error?

Start with the exact screen and the penalty portal. Amazon calls "Login Blocked: Suspicious Software or Corrupted Install Detected" an EAC detection block and treats "[EAC Offline]" as a service or connectivity error. Neither is published as an HWID-ban message. A recorded penalty confirms account enforcement; a repeating restriction tied to the same PC may justify examining the machine profile, but Amazon does not disclose a public hardware-match test.

Which hardware identifiers can contribute to a New World EAC profile?

Relevant Windows surfaces include the SMBIOS Type 2 baseboard serial, system or motherboard UUID, physical disk firmware serials queried through IOCTL_STORAGE_QUERY_PROPERTY, filesystem volume serials, physical NIC MAC addresses, and MachineGuid under HKLM\SOFTWARE\Microsoft\Cryptography. TPM 2.0 endorsement-key material and Secure Boot state can add identity or context. EAC does not publish New World's exact selection or weighting, so this is a surface map, not a leaked schema.

Will reinstalling New World, Steam, or Windows clear a hardware ban?

Reinstalling New World or Steam replaces application files, not the PC's board, disk, or network identity. Reinstalling Windows can regenerate MachineGuid and formatting can change volume metadata, but the SMBIOS Type 2 serial, motherboard UUID, physical disk firmware serials, and factory NIC identity can remain. A reinstall can fix a damaged EAC service. It should not be treated as proof that the durable machine profile changed or that Amazon removed the account penalty.

Will a new Steam account work after a New World hardware ban?

A different Steam login changes the account identity, not the hardware values presented by the PC. If the restriction is device-linked, the same board, storage, Windows, and network surfaces remain available for correlation. Amazon also says creating new accounts to evade disciplinary action can lead to additional enforcement. Do not use an alternate account as a diagnostic test; inspect the original penalty and use the one official appeal provided for it.

Does a New World EAC ban automatically ban Lost Ark, Fortnite, or Rust?

No universal EAC roster-wide ban is documented. Those games can use the same anti-cheat engine and encounter the same classes of board, disk, Windows, network, and security-state values, which creates cross-game fingerprint exposure. Publishers still administer their own accounts and sanctions. Amazon's appeal page separately acknowledges that some penalties may affect all Amazon Games titles, but that is publisher-level enforcement, not proof that every EAC publisher shares one ban list.

Can I appeal a New World hardware or permanent ban?

Use Amazon's New World penalty portal and sign in through Steam. Amazon says each penalty can be appealed once, so include the exact message, penalty record, relevant dates, account-security evidence, and any media URL in that submission. A moderator can approve, deny, or close the appeal, but Amazon does not promise disclosure of EAC detection details. A hardware rewrite cannot erase the server-side account sanction or substitute for an approved appeal.

How long does a New World HWID ban last?

Amazon publishes warning, restriction, suspension, and permanent account outcomes, but it does not publish a separate New World HWID-ban countdown or device-reset date. Treat a permanent account penalty as having no stated expiry unless the penalty portal or an approved appeal says otherwise. Do not rely on a forum claim that the machine record clears after a fixed number of days; no first-party New World source verifies such a timer.

Can a used motherboard or second-hand PC carry a New World hardware match?

A used machine can present the previous owner's SMBIOS board serial, motherboard UUID, disk firmware serials, and factory network identifiers. That makes inherited device correlation technically possible. Amazon does not publish New World's match threshold, however, so a first-launch block on a used PC is not proof that you inherited an HWID ban. Check the exact EAC message, Steam penalty record, service health, and software state before blaming a component.

Do TPM 2.0 and Secure Boot identify a banned New World PC?

TPM 2.0 can expose endorsement-key material rooted in the physical security processor, while Secure Boot reports whether the UEFI boot chain is trusted. They are different surfaces: one can contribute durable identity, the other describes platform integrity. Neither Amazon nor Epic publishes a New World rule saying either value is a universal ban key. Do not clear the TPM or change firmware settings to test a penalty; that can create recovery and boot problems without resolving the account action.
