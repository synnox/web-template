# Web Template

Ce repository regroupe différents projets web réalisés par **Synnox**, principalement dans le cadre de l'apprentissage, de l'expérimentation et de l'amélioration de mes compétences en développement web.

## À propos

Les projets présents dans ce repository peuvent être des créations personnelles, des expérimentations ou des reproductions de sites web existants.

Certains projets ont été entièrement imaginés et développés par moi. D'autres sont basés sur des sites déjà existants et reprennent volontairement une grande partie, voire la quasi-totalité, de leur apparence, de leur structure et de leur fonctionnement.

Le but de ces reproductions est avant tout **éducatif** : elles permettent de m'entraîner à analyser une interface existante, à comprendre sa construction et à essayer de la recréer le plus fidèlement possible.

## Reproductions

Lorsqu'un projet est basé sur un site existant, celui-ci peut reprendre de nombreux éléments du projet original, notamment :

* La structure générale
* L'organisation des pages
* La mise en page
* Le design et l'interface
* Les interactions
* Certains éléments visuels
* Le comportement général du site

Ces projets peuvent donc être très proches de leur référence d'origine. Cette ressemblance est volontaire et fait partie de l'exercice.

## Objectif

L'objectif de ce repository est de conserver une trace de mes différents projets et de mon évolution dans le développement web.

Les reproductions me permettent notamment de travailler ma capacité à :

* Observer et analyser une interface
* Reproduire fidèlement un design
* Comprendre la structure d'un site
* Transformer une référence en projet fonctionnel
* Améliorer mes compétences techniques
* Expérimenter différentes approches de développement

## Disclaimer

Les projets qui reproduisent des sites existants sont réalisés uniquement dans un objectif **personnel et éducatif**.

Lorsqu'un projet reprend le design, la structure, les éléments visuels, les marques, les logos ou d'autres éléments provenant d'un site existant, ceux-ci restent la propriété de leurs créateurs ou propriétaires respectifs.

Aucun projet présent ici n'a pour objectif de faire passer une reproduction pour le site original ou de revendiquer la propriété du travail repris.
